# Ближе

Авторская концепция анимированного сайта-приглашения: предметный билет, тканевая сцена, фотолента и интерактивная программа вечера.

Фотолента использует адаптивные WebP и встроенные мини-превью. Часы показывают время выбранного пункта программы, а тёплая гирлянда постепенно загорается при прокрутке. Однократные появления, ручная пауза и reduced-motion сохраняют доступность содержания.

Статический HTML/CSS/JavaScript без установки пакетов и сборки. GitHub Pages публикует корень ветки `main`; `.nojekyll` отключает обработку Jekyll.

Мероприятие вымышленное. Ответ на приглашение показывает выбранный вариант локально и не передаёт данные.

Шрифты Dela Gothic One и Golos Text размещены локально; лицензии SIL OFL находятся в `fonts/`. Фотографии используются по Unsplash License; авторы и первичные страницы записаны в `assets/atmosphere-*.webp.json`. Фон, металлический объект, лента и два состояния лампы созданы специально для проекта; промпты сохранены в соответствующих файлах происхождения.
